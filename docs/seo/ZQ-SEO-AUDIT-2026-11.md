## Scope and sources

The supplied local property directories cover web search from 26 May to 25 November. CSV, JSONL and raw API dataset counts and the sitemap responses are recorded in [monitoring JSON](../../reports/seo/gsc-monitoring.json). Working baseline: `origin/main` at `6412c60`; PRs #113–119 already address titles, link hygiene, reporting, reviews and approved pricing. The original dirty checkout was left intact. This is Astro (static catch-all plus a booking route), Tailwind, a Node content/post-processing pipeline, Vercel routes and Playwright. No framework migration is needed.

- The [sitemap verification](../../reports/seo/live-sitemap-verification.csv) covers **79 unique page URLs**, all direct 200, one exact apex canonical, no noindex, one H1 per page. The reported 158 web entries include 79 repeated page URLs in the image sitemap; 227 image associations referenced 13 unique images. Zero duplicate titles/descriptions, zero old-domain links and zero missing inbound pages within this audit corpus. 82 distinct internal destinations returned 200; fragment-level reachability not exhaustively verified.
- Live URL Inspection API: homepage, office, prices, Hyde Park, Unley Park and piano are **submitted and indexed**, and Google-selected canonical matched for all six. This is a six-URL sample, not whole-site coverage.
- Nine requested widths were sampled across home, About, office, prices and contact with reduced motion, no overflow observed, and production baseline images captured at 390 and 1440 px. Existing conversion events include consent-gated quote acceptance, calls, emails, quote start and price CTA clicks. There is no verified separate booking completion event to instrument.
