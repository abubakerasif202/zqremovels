# ZQ Removals V6 Strategy Roadmap: The Bridge to V7

**Goal:** Serve as the crucial consolidation phase bridging the massive programmatic SEO generation of V5 and the high-trust, hyperlocal focus of V7. V6 focuses on "Balanced Bridging"—solidifying architecture, mastering tracking/conversion, optimizing assets, and establishing local dominance systems (GBP/Reviews) so that traffic generated by V5 actually converts, and the foundation is ready for V7.

---

## 1. Critical Issues & Technical Debt

Before building new features, we must secure the current state:

*   **Architecture & Build System Clean-Up:** V5 added immense complexity to `site-src/data/seo-v4.mjs` and `scripts/build-site.mjs`. We need to extract the generation logic into modular files (e.g., `generators/suburbs.mjs`, `generators/routes.mjs`) to prevent `build-site.mjs` from becoming a monolithic bottleneck.
*   **Static `pages.json` Deprecation:** As noted in V5 completion, interstate routes are still partially defined in `pages.json`. This dual-source-of-truth must be fully migrated to the programmatic generator.
*   **Image Optimization Pipeline:** While `scripts/optimize_images.py` and `scripts/optimize-images.mjs` exist, they need to be integrated into a seamless build step ensuring WebP/AVIF generation, proper `srcset` mapping in HTML, and strict pre-loading for LCP (Largest Contentful Paint) assets.
*   **Schema Guardrails:** Ensure `seo-v5.test.mjs` strictly enforces that only `LocalBusiness` schema is used on service pages, and `Article` schema is strictly isolated to guide pages to avoid Google Search Console penalties.

## 2. High-Impact Quick Wins

Immediate value generation with low engineering effort:

*   **Implement Tracking V6 Plan:** Immediately roll out the GA4 events defined in `tracking-v6-plan.md` (`quote_form_submit`, `click_to_call`, `sticky_cta_click`) into the static templates. This is critical to measure V5's success.
*   **UTM Standardisation:** Enforce the GBP UTM parameters (`utm_source=google&utm_medium=organic&utm_campaign=gbp`) across all Google Business Profile links immediately to separate local map pack traffic from organic search traffic.
*   **Sticky Mobile CTA:** The newly designed dark luxury aesthetic (`1e59a04`) is beautiful on desktop. On mobile, ensure a high-contrast, sticky "Get a Quote" or "Call Now" bar remains visible at all times to drastically improve mobile lead capture.
*   **Dynamic FAQs on Routes:** Port the successful dynamic FAQ generation from the suburb pages over to the Interstate Route pages to capture 'People Also Ask' features.

## 3. Long-Term Architecture Upgrades

Preparing the codebase for the next 2-3 years:

*   **Modular Static Generator:** Refactor the custom Node.js static site generator. Move from a single script to a pipeline: `Data Ingestion -> Template Compilation -> Asset Optimization -> HTML Minification`. This prepares us for a potential future migration to Astro or Next.js if dynamic server-side rendering becomes necessary.
*   **Headless CMS Integration Prep:** Currently, data lives in `.mjs` files. Plan an abstraction layer so that in V7 or V8, content can be pulled from a headless CMS (Sanity, Contentful) to allow non-technical staff to update copy without a git commit.
*   **Lead Capture API Hardening:** The `api/quote.js` serverless function needs robust rate-limiting, honeypot fields to prevent spam, and structured error handling to ensure zero lost leads during high-traffic periods.

## 4. Premium Brand Improvements

Executing the "Dark Luxury" vision across all touchpoints:

*   **UX Consistency:** Ensure the new `--gold-deep` and `--color-bg-soft` (`#0a1220`) variables are applied universally, especially to generated suburb and route pages which often lag behind homepage styling.
*   **Tactile Interactions:** Implement micro-interactions (subtle hover states, smooth scroll reveals, soft shadows) defined in the new CSS across the conversion funnel (quote forms, calendar pickers).
*   **Premium Asset Sourcing:** Replace generic stock imagery with high-quality, branded photography (or highly controlled AI generation) that matches the high-end editorial palette.

## 5. Autonomous Content Generation Opportunities

Scaling content without scaling headcount:

*   **Dynamic Review Integration:** Build a script to safely ingest 5-star Google Reviews via API at build time, categorize them by intent (e.g., "Interstate", "Careful with Antiques"), and inject them into the relevant suburb/route generated pages.
*   **Automated Content Refreshing:** Implement the `content-refresh-v6-calendar.md`. Build a system that flags pages untouched for 6 months and automatically drafts a slightly revised, updated version (e.g., updating "2025" to "2026", refreshing local context) for manual review.

## 6. AI-Assisted Workflow Opportunities

*   **Review Response Automation:** Use AI to draft contextual, keyword-rich responses to new Google Reviews (noting the specific suburb or service mentioned) to boost local SEO relevance.
*   **Competitor Gap Analysis Script:** Write a script that regularly scrapes the top 3 ranking pages for our core keywords and cross-references them against our `site-src/data` to automatically output missing entities/keywords into a `TODO_seo-auditor.md`.

## 7. Competitor Domination Strategy

Executing the `competitor-outrank-door2door-plan.md` and `local-citation-v6-plan.md`:

*   **NAP Consistency Enforcement:** Run a full audit and synchronization of Name, Address, Phone across all Tier 1 local directories (Yelp, TrueLocal, YellowPages).
*   **Hyper-Local Content Gaps:** Explicitly attack competitor weaknesses by adding "Fixed-Price Guarantee" and "Specific Suburb Access Planning" modules to all local pages, as identified in the competitor outrank system.
*   **GBP Post Automation:** Establish a system for weekly Google Business Profile posts utilizing the generated visual assets to maintain an active, highly relevant local presence.

## 8. Conversion Optimization Roadmap

Turning traffic into revenue:

*   **Frictionless Quote Funnel:** Analyze the current drop-off rate on `api/quote.js`. Redesign the form into a multi-step, conversational wizard (e.g., "Where from?" -> "Where to?" -> "Size of home?" -> "Contact details") rather than a massive single-page wall of inputs.
*   **Trust Anchors:** As a prelude to V7, strategically place Trust Signals (AFRA mentions, specific insurance coverage details, established year) immediately next to every primary CTA button.
*   **Post-Conversion Nurture:** Implement the `review-request-v6-system.md`—automated SMS/Email sequences post-move to drive Google Reviews, creating a self-sustaining local SEO loop.
