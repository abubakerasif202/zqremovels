Audit date: 23 October 2026. Preferred domain: `https://zqremovalsadelaide.com.au/`. Historical domain: `https://zqremovals.au/`.

The supplied old-domain ZIP was read directly without extracting its many daily CSV files. The new-domain CSV export covers 30 August–19 October 2026. Both properties use Web Search.

Raw property sums are 33 clicks / 6,154 impressions over the matched 28 days, and 64 clicks / 13,360 impressions over the matched 51 days. These are **not deduplicated site totals**: query/page overlap can cause the same search activity to appear under both properties. No combined average position is reported because averaging property positions would be misleading and the exports do not allow reliable deduplication.

The old-domain 28-day history fell from 26 clicks / 6,336 impressions (25 Aug–21 Sep) to 10 / 1,802 (22 Sep–19 Oct), while its reported average position improved from 21.79 to 13.48. The new-domain export has 23 clicks / 4,352 impressions for the latest 28 days. This establishes continuing visibility on the new property; it does not by itself establish how much traffic transferred, because the first new-domain daily row is 30 August and the properties overlap.

One brand-query comparison in the matched 51-day export supports transfer: `zq removals` had 2 clicks / 95 impressions on the old property and 13 / 90 on the new property. Query-level rows are privacy-filtered and do not sum to property totals. These observations are not causal proof of the migration's effect.

## Follow-up live route check — 23 October 2026

A fresh request-chain check confirms the old-domain platform redirect is active but the current Production deployment lacks the path mapping: each `https://zqremovals.au/guides/.../` responds **308** to the identical path on `https://zqremovalsadelaide.com.au/`, which responds **404**. The three intended destinations each respond **200** and expose their own apex canonical. Current branch `vercel.json` contains permanent path mappings, and the local build includes each target with a self-canonical and sitemap entry. Deploying this branch is required to test the mappings in Vercel; if the post-deploy chain still returns 404, investigate Vercel domain/route precedence before release. Do not describe Production as fixed before a live 301/308→200 check passes.
