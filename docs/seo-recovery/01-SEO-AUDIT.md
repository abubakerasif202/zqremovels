## Repository and generated output

- The production source is the static-site generator in `scripts/build-site.mjs`, `site-src/pages.json`, `site-src/data/`, `site-src/content/` and shared partials. Astro renders route entry points; the generator then emits and post-processes `site-dist/`. Generated files are not the edit surface.
- Redirects are configured in `vercel.json`; route aliases are also represented in the generator registries. Canonicals, JSON-LD and five XML sitemap files are generated from the registered page metadata.
- `robots.txt` permits public crawling and advertises `https://zqremovalsadelaide.com.au/sitemap.xml`.
- Quote forms post through `/api/quote/` when JavaScript is available and retain the existing provider form action as a no-JavaScript fallback. GTM is loaded by the existing layout with container `GTM-WJGKPXFL`.

## Local validation

- `npm run build`: passed; Astro emitted 122 pages.
- `npm run seo:validate`: passed; 108 route records checked, zero bad pages, 79 indexable sitemap URLs across four child page sitemaps and one sitemap index, 28 redirect exclusions, one noindex exclusion.
- `npm test`: completed successfully, including the quote API smoke check and repository Node tests. Playwright conversion/mobile checks were run separately.
- `npx tsc --noEmit`: passed.
- The accepted conversion event contract is covered by regression tests: `zq_quote_submitted`, `form_name=quote_form`, `submission_status=accepted`, and a server-confirmed UUIDv4 `submission_id`.

## Scope and remaining evidence

This checkout contains substantial pre-existing uncommitted work on quote acceptance tracking, CSS output and migration redirects. The audit reviewed and validated that work in place; it did not reset or replace it. No production deployment, Google Ads edit, GTM publish, live quote submission, or GSC account mutation was performed.

The live migration crawl is a snapshot from before this local branch was released. Its three 404 destinations are generated by the current build, so the source fix is present locally; only a post-release live request can close that finding. Field Core Web Vitals and native iOS/Android keyboard behavior remain unverified.
