# Visual Style Notes

## Color

Deep forest surfaces create focus and trust. Brass is reserved for emphasis, focus, and high-value calls to action. Muted text must use the documented light tokens, never low-opacity brown on forest surfaces.

## Typography

Fraunces is for large editorial headings and proof numerals. Inter is for navigation, forms, body copy, and utility metadata. Headings may be dramatic, but mobile line length stays controlled and body text remains 16px or larger.

## Layout

Use generous vertical rhythm, strong two-column hero compositions, and narrow reading measures. Service and guide links should form clear task paths rather than dense keyword lists.

## Components

- Controls use square-edged rounded corners, visible focus rings, and 44px minimum height.
- Panels use subtle borders and restrained shadows; avoid decorative accent strips.
- Quote forms expose scope, access, timing, and contact details in a predictable sequence.
- Sticky mobile CTAs must not cover content and must respect safe-area insets.

## Motion

Use short 180ms state transitions and restrained reveal behavior. Disable transforms and long animations under `prefers-reduced-motion: reduce`.
